# MASTER PROMPT — ГРАФИКА ×100 АГЕНТОВ («ФРОНТИР»)

Вставь этот файл ЦЕЛИКОМ в новый чат ИИ. Ты — ведущий графики игры «ФРОНТИР»,
тебе выдан бэклог из 100 улучшений: `docs/ГРАФИКА_100.md` (прочитай ПЕРВЫМ).
Твоя задача — внедрить все 100 силами роя: 10 волн по 10 агентов, волна = одна
категория бэклога (Спрайты зданий → Ландшафт → Вода → Атмосфера → Свет →
Жители → Армии → UI → Постэффекты → Камера+Кинематограф).

## ГДЕ РАБОТАЕМ
- Репо: molotroka123-cell/frontier-evo, ветка **ai/graphics-glow** (графическая).
- Основную ветку ai/alpha-safe-improvement НЕ ТРОГАТЬ: там живёт логика/контент.
- Изоляция через `git worktree add %TEMP%\opencode\gfx100 ai/graphics-glow`
  + junction node_modules. Все агенты работают в worktree.
- Запрещено трогать: app/src/core/**, integrate.js, simulation.js, data.js —
  графике туда хода нет. render/ и ui/ — твоя территория.

## ЖЕЛЕЗНЫЕ ПРАВИЛА (нарушение = переделка агентом)
1. Детерминизм: ни Math.random, ни sim.rng в render/**. Случайность — только
   hash(sim.world.seed, x, y, кадр). Кадры у игроков разной частоты — сейвы
   не должны плыть.
2. Render не мутирует sim. UI не мутирует sim. Только чтение.
3. Тяжёлый эффект = гейт по quality.js (eco молчит, medium урезан, high/ultra
   полные) + потолок частиц/объектов на кадр + отсечение вне камеры.
4. FPS: замер максимумом из ТРЁХ прогонов tools/shot.mjs до и после. Просадка
   >5 кадров на сцене с фиксированным сидом = эффект выключается гейтом и
   возвращается на доработку. Шум машины ±10 — сравнивай максимумы.
5. Скриншоты СМОТРЕТЬ ГЛАЗАМИ (Read картинки): «до» и «после» на каждый пункт.
   Сгенерировать и не посмотреть = не сделано.
6. UTF-8 без BOM, LF. Никаких PowerShell-редиректов. Никаких .patch и wip.
7. Модуль без подключения не сделан: новый файл = импорт + вызов + grep по
   собранному frontier.html с числом в отчёте.
8. Общие файлы (renderer.js, hud.js, main.js, sprites.js, build.mjs,
   quality.js) правит ТОЛЬКО ведущий (ты), по блокам «ПОДКЛЮЧЕНИЕ» агентов:
   якорь-строка целиком + число совпадений grep (=1) + готовая вставка.
   Перед каждой вставкой перепроверь якорь сам — файл мог уехать.
9. Агент = один пункт бэклога = один новый файл + его тест (или правка своего
   же файла из прошлой волны). Агенту запрещены npm run build, tools/shot.mjs
   (порт/артефакт), git commit/push. Свой превью-скрипт playwright — во
   %TEMP%\opencode\<агент>\, порт из диапазона 8500–8599.
10. В коммите только проверенное: числа тестов, grep-числа. «НЕ СДЕЛАНО» —
    прямым текстом. Ложь в коммите = переделка всей волны.

## ПРОТОКОЛ ВОЛНЫ (повторить 10 раз)
0. Ведущий: `npm test` зелёный? Зафиксируй baseline FPS (3 прогона).
1. Запусти 10 агентов параллельно — по пункту на агента. В промте агента:
   номер пункта, его текст из бэклога, зона владения (1 файл + тест),
   требование «скриншот до/после глазами», чистая математика отдельно от
   draw-кода (тестируется в node без canvas), гейты качества.
2. Собери отчёты: СДЕЛАНО/НАЙДЕНО/НЕ СДЕЛАНО/ОТСТУПЛЕНИЯ + блоки ПОДКЛЮЧЕНИЯ.
3. Примени блоки к общим файлам ПО ОДНОМУ, после каждого — точечные тесты.
4. `npm test` (всё зелёное, проверок не меньше было) → `npm run build` →
   grep новых модулей в frontier.html → `npm run shot` (консоль 0 ошибок) →
   FPS-сравнение с baseline.
5. Атомарный коммит на группу пунктов (не валить волну в один коммит) →
   `git push origin ai/graphics-glow`.
6. Дашборд: допиши строку в docs/ГРАФИКА_ДАШБОРД.md —
   `- ЧЧ:ММ | волна N | пункт №X «название» | агент | статус | тест N/M | FPS до→после`.
