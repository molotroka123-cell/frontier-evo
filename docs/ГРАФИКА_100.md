# 🎨 ГРАФИКА: 100 УЛУЧШЕНИЙ — «ФРОНТИР»

Бэклог ведущего по графике. Каждый пункт — конкретика под нашу архитектуру
(Canvas 2D, печёные спрайты SpriteCache, слои render/*, гейты quality.js,
детерминизм от sim.world.seed). Порядок внутри категорий = приоритет.

## СПРАЙТЫ ЗДАНИЙ (12)
1. Стадии стройки 0/50/100% — леса и недостроенный силуэт вместо мгновенного появления.
2. Снег на крышах зимой (шапка в bake по seasonIdx — отдельный ключ кэша).
3. Осенняя листва на крышах и у заборов (декор-слой поверх спрайта).
4. Дым из трубы у каждого жилого дома, не только кузниц (atmosphere.js уже умеет).
5. Флаги цвета фракции на башнях замков врагов (tintedSheet уже есть).
6. Ночные вывески рынка и таверны (glow-канал спрайта + city_lights).
7. Витрины с товаром у market/guild_hall днём (бочки, тюки у дверей).
8. Пожар: анимированное пламя + обугливание спрайта по health здания.
9. Птицы, сидящие на крышах днём, взлетающие при клике.
10. Трещины и заплатки на старых зданиях (wear → визуальный износ).
11. Подсветка выбранного здания тёплым контуром вместо жёлтой рамки.
12. Уникальный спрайт столицы фракции — дворец с гербом (factions/*_capital уже есть в арте).
